# DESIGN.md

## Direction

Clean, warm, modern Islamic school landing page.

Primary visual identity:

- navy
- yellow
- white
- real photography
- restrained typography
- generous whitespace

## Hierarchy

1. clear headline;
2. short supporting copy;
3. direct CTA;
4. proof points;
5. program explanation;
6. PPDB information;
7. conversion.

## What Makes This Site Distinct

Not decorative "Islamic" motifs.

Identity comes from:

- school logo;
- real school photography;
- program content;
- navy/yellow palette;
- disciplined editorial layout.

## Prohibited Default Patterns

- generic AI SaaS hero;
- glass panels;
- bento-grid-first composition;
- decorative sparkle;
- status dot;
- pill overload;
- giant rounded cards;
- random gradients;
- fake numbers;
- fake testimonials;
- generic illustration.

## Responsive

Design must work continuously across phone, tablet, small laptop, desktop.

## Photography

Prefer original assets over generated visuals.

If high-quality photography is unavailable, use solid color and typography instead of fake visual filler.
