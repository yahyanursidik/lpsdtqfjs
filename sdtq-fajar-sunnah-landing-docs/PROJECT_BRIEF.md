# Project Brief — Landing Page PPDB SDTQ Fajar Sunnah

## 1. Nama Proyek

Landing Page PPDB SDTQ Fajar Sunnah 2027/2028

## 2. Tujuan Bisnis

Membantu calon orang tua:

1. mengenal SDTQ Fajar Sunnah dalam waktu singkat;
2. memahami program inti sekolah;
3. melihat kecocokan pendidikan;
4. mengetahui jadwal dan biaya PPDB;
5. menghubungi admin tanpa hambatan;
6. melanjutkan ke formulir pendaftaran.

## 3. Primary Conversion

Urutan konversi:

1. `Daftar PPDB`
2. `Tanya via WhatsApp`
3. `Lihat Instagram`

## 4. Target Pengguna

Utama:

- orang tua calon siswa usia SD;
- orang tua siswa pindahan;
- orang tua yang mencari sekolah dasar Islam dengan program tahfidz di area Lembang dan sekitarnya.

## 5. User Questions yang Harus Dijawab

Dalam kurang dari 60 detik, user harus bisa memahami:

- sekolah ini apa;
- apa yang membedakan programnya;
- target tahfidz berapa;
- apa saja kurikulumnya;
- apakah menerima siswa pindahan;
- di mana lokasinya;
- berapa biaya masuk;
- kapan pendaftaran;
- bagaimana cara mendaftar;
- siapa yang bisa dihubungi.

## 6. Pesan Utama

Headline:

> Menghafal Al-Qur'an, Membangun Masa Depan

Supporting message:

> SDTQ Fajar Sunnah mengintegrasikan program Al-Qur'an, pendidikan keagamaan, pembelajaran umum, dan pengembangan minat bakat anak.

## 7. Value Proposition

Fakta yang diprioritaskan:

- target hafalan 3–6 juz selama 6 tahun;
- tahfidz dan tahsin;
- pendekatan personalized learning;
- kelas tahfidz eksklusif;
- rasio 1 pengampu : 7 siswa untuk halaqah;
- integrasi kurikulum keagamaan dan kurikulum pendidikan umum;
- nilai dan capaian pembelajaran dapat diakses realtime;
- kegiatan ekstrakurikuler beragam;
- menerima siswa baru dan pindahan.

## 8. UX Principle

Landing page harus terasa:

- hangat;
- terpercaya;
- bersih;
- modern;
- tidak ramai;
- mudah dipindai;
- realistis;
- sesuai karakter sekolah.

Landing page tidak boleh terasa:

- seperti template startup SaaS;
- seperti brosur yang dipindah apa adanya;
- penuh badge;
- penuh card;
- penuh gradient;
- penuh ornamen;
- penuh animasi;
- penuh copy promosi generik.

## 9. Mobile-first

Mayoritas traffic diasumsikan datang dari:

- WhatsApp;
- Instagram;
- browser mobile.

Karena itu CTA harus mudah dijangkau di layar kecil.

## 10. Definition of Done

Landing page dianggap selesai jika:

- seluruh konten utama hadir;
- seluruh CTA bekerja;
- responsive pada mobile, tablet, dan desktop;
- tidak ada horizontal overflow;
- Lighthouse target terpenuhi;
- SEO metadata lengkap;
- Open Graph lengkap;
- foto teroptimasi;
- keyboard navigation bekerja;
- contrast cukup;
- tidak ada placeholder/TODO yang tidak disengaja;
- quality gate anti-slop lulus.
